# 6R Diamond HR Management System
## Complete User Manual (Installation and Utilization)

## 1. Purpose of This Manual
This guide explains how to:
- Install the desktop app on Windows
- Open and use the app for daily HR work
- Resolve common issues quickly

---

## 2. System Requirements
- Windows 10 or Windows 11 (64-bit)
- Stable internet connection
- At least 500 MB free disk space

Note:
- Internet is required because the app connects to an online backend service.

---

## 3. Installation Guide

### 3.1 Download the Installer
Download the official installer file:
- `6R Diamond HR Management System-Installer-1.0.0-x64.exe`

Only download from your organization-approved source.

### 3.2 Run the Installer
1. Double-click the `.exe` installer.
2. If Windows asks for permission, click `Yes`.
3. Follow the setup wizard and click `Install`.
4. Wait for installation to finish.
5. Click `Finish`.

### 3.3 Open the App
You can launch the app through:
1. Desktop shortcut: `6R Diamond HR Management System`
2. Start Menu search: `6R Diamond HR Management System`

---

## 4. First-Time Use

### 4.1 Sign In
1. Open the app.
2. Enter your HR credentials.
3. Click `Login`.

If you forgot your password:
1. Use the `Forgot Password` flow.
2. Follow verification prompts.
3. Set your new password and sign in again.

### 4.2 Verify Connection
After login, confirm data loads correctly.
If dashboards/tables are empty due to loading errors, check your internet first.

---

## 5. Main Features and How to Use Them

## 5.1 Dashboard / Overview
Use this area to view summary information such as:
- Applications overview
- Interview-related metrics
- Quick status insights

Recommended routine:
1. Check totals and trends.
2. Identify urgent actions for the day.

## 5.2 Applicants
Use this section to:
- Review applicant records
- Open applicant details
- Update applicant status when needed

Best practice:
1. Search/filter applicants first.
2. Review profile details carefully.
3. Update status only after final decision.

## 5.3 Schedules
Use this section to:
- Select applicants for interview scheduling
- Assign interview dates and time slots
- View grouped interview schedules

Recommended workflow:
1. Select branch and applicants.
2. Assign date.
3. Assign time slots to each selected applicant.
4. Complete scheduling.
5. Confirm entries in Interview view.

## 5.4 Job Postings
Use this section to:
- Create job postings
- Edit job details
- Open/close postings
- Remove outdated postings

Best practice:
1. Keep role title and branch accurate.
2. Review posting status (active/inactive) regularly.

## 5.5 Reports
Use this section to:
- Generate HR reports
- Filter by date/period/branch
- Export report output when needed

---

## 6. Daily Utilization Checklist
Start of day:
1. Open app and log in.
2. Check Dashboard/Overview.
3. Review new applicants.

During day:
1. Schedule interviews.
2. Update applicant statuses after interviews/decisions.
3. Maintain job posting availability.

End of day:
1. Generate reports.
2. Verify schedule updates and status updates are saved.

---

## 7. Troubleshooting

## 7.1 App Does Not Open
1. Restart your PC.
2. Re-open from Start Menu.
3. If still failing, reinstall using the official installer.

## 7.2 App Opens but Data Does Not Load
1. Check internet connection.
2. Close and reopen the app.
3. Try again after 1-2 minutes (server may be restarting).

## 7.3 Login Fails
1. Re-check employee ID and password.
2. Use forgot password if needed.
3. Contact your admin if account access is still blocked.

## 7.4 Installer Warning (Windows SmartScreen)
If prompted:
1. Click `More info`.
2. Click `Run anyway`.
Only proceed if installer is from your official source.

## 7.5 Feature Error or Unexpected Behavior
Collect and provide:
1. Screenshot of error
2. Time and date of issue
3. Action you performed before the issue
Send these to your support/admin team.

---

## 8. Update and Reinstallation
When a new version is released:
1. Download latest installer from official source.
2. Run installer.
3. Complete setup.

If prompted, uninstall old version first, then install the new one.

---

## 9. Security and Usage Notes
- Do not share your login credentials.
- Use only official installer links from your organization.
- Keep internet active while using the app.
- Log out when leaving shared workstations.

---

## 10. Quick Start Summary
1. Download official installer.
2. Install and launch app.
3. Log in with HR credentials.
4. Use Dashboard, Applicants, Schedules, Job Postings, Reports.
5. Keep internet connection on at all times.
